# FluxSave

FluxSave is a fast desktop media downloader for macOS and Windows.

## Features

- Public YouTube and social-video links
- QuickTime-compatible MP4 downloads
- Resolution selection
- MP3 extraction
- Original source titles
- Parallel fragment downloading

## Downloads

Installers are published on the [Releases](https://github.com/lightscameratech-art/fluxsave/releases) page.

## Responsible use

Download only media you own or have permission to save. Private and DRM-protected media are not supported.
